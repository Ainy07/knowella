# CSV/Excel File Processing API

## Overview

This project is a Django REST API that processes CSV and Excel files. Users can upload files, apply configurable operations using a JSON rule engine, store results in a database, and export processed data to a new CSV file.

The project demonstrates backend data processing using Django, Pandas, and REST APIs.

---

## Features

- Upload CSV and Excel files
- Configurable rule-based data processing
- Data transformation using Pandas
- Store processed data in database
- Export processed data to CSV
- Download processed file via API

---

## Technologies Used

- Python
- Django
- Django REST Framework
- Pandas
- SQLite
- JSON

## API Endpoints

### Upload File

POST `/api/upload/`

Uploads a CSV or Excel file and processes it according to configuration rules.

---

### Download Processed File

GET `/api/download/`

Downloads the processed CSV file generated by the system.
